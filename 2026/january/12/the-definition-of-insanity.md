# The Definition of Insanity

Because I love rehashing things I've done over and over again instead of working on anything that will actually teach me anything, I once again initialised my crate with Axum and Askama and packaged it as a Nix package and container image. This time though, I didn't bother with GCP - I have tried it twice for two projects now, and it's enough to turn me off from it for a lifetime. I already set up workflows I'm pretty happy with (meaning I won't refactor them for no reason again as I am wont to do) to build, tag, and deploy the images to GHCR, but in my mission to do everything correctly the first time for my tools repo (which is this month's project), I can't just deploy to fly.io or something and call it a day. Tomorrow I'll start work on wiring up Terraform to AWS and set up Fargate and ALB to receive my DNS records. I am really dreading the security group stuff, but I hope it goes much better than GCP did. Regardless, the goal remains to have the website up by the end of the week so I can finally start on front-end next week - I want to get through as much of the MDN curriculum as I can before the end of January because I've told myself every month has to alternate between a new project and old, and I think I pretty much have to at least learn either Go or React if I want to be as marketable as I can. I'll miss working with Rust, but if I set my tools up correctly I think I should be fine to make smaller Rust contribs to my existing projects. Anyway, that's all for tonight - see ya tomorrow :)
