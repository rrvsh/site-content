I've always been looking for a nice way to view RSS feeds for as long as I can remember. All the results on Google show me proprietary solutions or unsatisfactory ones. I just wanted an easy to use, open source solution that worked across all my devices.

Yesterday I again looked for a solution, and discovered [nom](https://github.com/guyfedwards/nom), which I set up and was committing to use, when I noticed that I could configure backends for it. I had heard of `miniflux` before this, but since it was self-hosted had neglected to consider it for now since I don't have my servers set up yet. Fortunately though, I did decide to at least give it a look. I found that [Miniflux](https://miniflux.app/) actually does have a hosted solution that costs $15 a year and would let me trivially export the feeds and metadata to another solution. Best of all, it can serve just as my server for me to client-hop as I wish. I've set it up with the following feeds, and I'm sure I will be adding more soon:

- [Julia Evans](https://jvns.ca/atom.xml)
- [NotAShelf's Blog](https://notashelf.dev/rss.xml)
- [Vaxry's Blog](https://blog.vaxry.net/feed)
- [Xe Iaso's blog](https://xeiaso.net/blog.rss)

That's all for today - see you tomorrow!
