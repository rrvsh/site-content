So I got home from work today, ready and willing to suffer in my wonderful GregTech New Horizons longplay, but to my horror, PrismLauncher wouldn't let me sign in with my Microsoft account. I genuinely thought it was an issue with my setup or the app, but after a restart and some googling, I found out the Minecraft auth servers have been down for hours. Thankfully, a lovely lad on GitHub has a fix - I won't post the link directly here because I got shouted at on Discord for posting it, but you might be interested in [this commit](https://github.com/rrvsh/tools/commit/33e8e4a6fa583b1cd94ec6752e22ba111355aea5) if you are running into the same issues :)

The error message for search (or LLM) indexing:

```
Failed to get Minecraft access token: Error transferring https://api.minecraftservices.com/launcher/login - server replied with status code 503
```
