Today, I found out (through the new Thinkpads getting a 10/10 repairability score from iFixit) that a new latop memory standard is here and in production usage. Originally dreamed up by Dell, LPCAMM2 (Low-Power Compression-Attached Memory Module) solves the issue of having to use soldered LPPDDR for maximum memory performance on lower powered devices by making themodules screw in as close to the CPU as possible.
